# 테스트 작성 규칙

1. 핵심이 아니면 테스트 코드를 만들지 않는다.
2. 유지·추가할 테스트는 다음 두 목적에 직접 해당하는 경우로 한정한다.
   - 개별 전략과 합성이 같은 조건에서 같은 목표 종목·비중을 사용하는지 검증한다.
   - 화면의 운용 결과와 백테스트 엔진 결과가 같은지 검증한다.
3. 전략 내부 현금 비중은 목표 비중 일치 검증에 포함한다. 현금·예산·정수 배분을 별도 테스트로 늘리지 않는다.
4. 문구·입력 검증·캐시 호출·내부 함수 구현·수집 처리 등은 별도 테스트를 만들지 않는다.
5. 기존 `test_screen_matches_backtest.py`를 우선 수정하고 같은 목적의 테스트 파일을 늘리지 않는다.
6. 사용자가 명시적으로 다른 범위의 테스트를 요청한 경우에만 예외로 한다.
