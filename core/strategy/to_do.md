# 전략 통합·리팩토링 — 남은 작업

최종 갱신: 2026-09-07. 계획(1~6단계)은 완료됐고, 아래 남은 체크만 유효하다.
상세 경위·검증 기록은 git 이력에 있다.

## 남은 체크리스트

- [ ] **다음 장중 화면 실검증** — 이번 작업은 전부 휴장일에 이뤄져 실시간 검증은
  가짜 시세 스모크·고정 입력 테스트까지다. 개장 후 확인할 것:
  - 모멘텀·신고가·합성 화면의 장중 판정(잠정 이탈·진입 예정)이 자연스러운지.
  - **국내 ETF 풀**: 시가를 안 주는 종목의 확정 주문이 "오늘 체결 예정"(`fill_date`)으로
    표시되고, 어제 종가 체결로 지어내지 않는지.
  - **한국 정규장 세션 폴백**: ETF 가 체결 시각(localTradedAt)을 안 줘도 세션 시계로
    장중(live)이 켜지는지 (`utils/slot_positions._live_quotes`).
- [ ] **실시간 마지막 봉 헬퍼 통일** (위 실검증 후 착수) — 같은 개념의 구현이 둘이다:
  ❗배지·순위는 `utils/rankings.build_effective_close_series`(오늘 날짜를 서울 시간 고정 —
  미국 풀에서 하루 어긋날 여지), 전략 장중 실행은 `core/strategy/intraday.effective_close_frame`
  (세션 날짜 인자). 하나로 통일. 장중 실검증 전에 바꾸면 문제 원인 구분이 안 되므로 뒤로 뒀다.
- [ ] **커밋** — 사용자가 몰아서 진행(요청 없이 커밋·푸시하지 않음). 커밋메시지는 준비돼 있다.

## 알아두면 좋은 정보 (동작 특성, 버그 아님)

- 잠정 진입의 표시 비중은 슬롯 1칸(슬리브/슬롯) 고정 — 현금 부족 축소는 체결(다음 시가) 때
  엔진이 반영하므로 장중 표시가 실제 체결 비중보다 클 수 있다.
- 운용 현황 API 응답에 `daily`(약 250행)가 실려 있다 — 합성 슬리브 몫이 같은 실행을 읽기
  위한 것으로, 전략 화면은 쓰지 않는다. 응답 크기가 신경 쓰이면 분리 후보.
- `daily.strategy_pct`의 소수 6자리 반올림은 페이로드 압축·복리 합성 오차 방지로 유지한
  기존 결정이다(다른 계산 입력 비중은 반올림 없이 전달).

## 완료한 작업 (1줄 요약)

- 공통 슬롯 엔진·모멘텀/신고가 신호·가격 패널·전략 문서를 `core/strategy/`로 이동, 옛 파일 제거.
- 포트폴리오 현금 초과 매수 수정(매도 선처리·가용액 내 매수·비율 축소).
- 참조 0인 `metrics.py`·`weight_allocator.py` 제거, `period_return_pct`는 `utils/price_series`로 이동.
- 엔진에 잠정 마지막 봉 모드 추가 — 장중 판정·체결·수량을 같은 엔진이 산출, 시가 미상 주문은
  체결 예정(fill_date/pending)으로 남기고 잠정 재판정이 확정 주문을 덮지 못한다(§10-6).
- 모멘텀·신고가 장중 화면을 엔진 잠정 실행으로 전환, 화면 수동 판정(체결 반영·잠정 청산·진입 선정) 제거.
- 진입 예정 전 행에 엔진 비중 전달, 합성의 누락 비중 1/N 대체 제거(누락 시 에러).
- 운용 현황 페이로드에 실행 `daily`를 실어 합성 슬리브 몫이 같은 실행을 읽음 —
  확정·장중 혼합 제거, 전략별 5분 캐시 하나로 중복 재생 제거(포트폴리오 현황도 캐시 추가).
- 포트폴리오 시뮬레이션(`portfolio/backtest`)·합성 재생(`mix/simulate`)·액션 조립(`mix/actions`)·
  목표 정수 배분(`mix/targets`)을 core 로 분리 — 수집·페이로드 조립은 `utils`에 유지.
- 생산자 없는 옛 경로(`rebalance`·`next_expected`·다음 주 미리보기) 전면 제거 — API·화면·타입 포함.
- 엔진 외부 조회(슬리피지·시작 자본·ADR·벤치마크) 인자화(`load_slot_market` 수집),
  운용 현황·슬리브 몫 캐시 키에 포함 — 풀 설정 변경이 즉시 반영된다.
- 검증: 핵심 테스트 8개(엔진 잠정 모드·장중 고정 입력 일치·포트폴리오 고정 입력 포함),
  변경 파일 전체 pre-commit·Next 빌드·tsc 통과, 합성 설정 전 계좌 읽기 전용 확인.
- 문서·화면 동기화: 전략 문서를 일간 슬롯 규칙으로 재작성, 모멘텀 화면 설명·합성 문구 갱신.
