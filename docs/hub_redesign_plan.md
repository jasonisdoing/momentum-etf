# 홈 허브(메뉴 겸 대시보드) 전환 계획

## 배경 / 목표
- 현재: 좌측 사이드바 + 우측 큰 그리드 구조. 사이드바가 그리드를 가려 작업성이 떨어짐(접힘 버튼은 있으나 잘 안 쓰게 됨).
- 목표: 홈(`/`)을 **메뉴 겸 대시보드(허브)** 로 만들고, 작업 화면은 **전체폭 라우트**로 사용.
  - 전체화면 모달 방식은 채택하지 않음 — URL/뒤로가기/멀티탭 유지를 위해 라우트 방식 사용.
- 원칙: **중간에 멈춰도 시스템 사용에 문제 없게** 단계별로 진행한다. 각 단계는 독립적으로 배포 가능해야 한다.

## 현재 구조 (2026-07-24 기준)
- `web/app/AppShell.tsx` — 사이드바(navGroups 정의 인라인) + 탑헤더 + 본문. `isSidebarCollapsed` 수동 토글 존재.
- `web/app/page.tsx` — 홈 `/` = `DashboardManager`(요약 대시보드) 이미 존재.
- 메뉴 그룹: 홈/보유종목/보유종목 상세(루트) + 계좌 · 정보 · 종목풀 · 레버리지 · 시스템 5그룹.

## 단계별 계획

### P1. 메뉴 정의 공용화 — ✅ 완료 (2026-07-24)
- `AppShell.tsx` 인라인 `navGroups`/루트 메뉴를 `web/lib/nav-menu.ts` 로 추출.
- AppShell 은 import 만 하고 동작 불변. 허브 타일과 사이드바가 **같은 메뉴 정의**를 공유(단일 소스).

### P2. 홈에 메뉴(허브) 추가 — ✅ 완료 (2026-07-24)
- 홈 `/` 를 `hubHomeLayout` 그리드로 구성: **대시보드(메인, 좌측) + 메뉴 레일(우측 250px, 카드 1장)**.
  - 처음엔 상단 타일 블록으로 넣었으나 대시보드와 따로 놀아서, 지표 카드와 같은 카드 스타일의
    우측 레일로 통합(스크롤 시 sticky). 좁은 화면(≤1100px)에서는 메뉴가 아래로 내려가 다열 그리드로 표시.
- 기존 대시보드(DashboardManager)는 내부 수정 없이 그대로 → "메뉴 겸 대시보드".
- 사이드바는 그대로 유지 — 이 단계까지는 순수 추가라 언제 멈춰도 안전.

### P2b. 홈 블록 조립(멀티 위젯 대시보드) — ✅ 완료 (2026-07-24)
- 화면 본문을 **재사용 패널로 추출**해(중복 구현 없이) 홈에서 블록으로 조립:
  - `Live24hBoard` (live-24h/HyperliquidClient.tsx) — 24H 시세 보드. 페이지와 홈 공용,
    `compact` 모드에서 시세 카드 3장(나스닥/환율/VIX)은 작게 한 줄, 비교 카드 3장은 크게.
    갱신시각 표기는 PageFrame titleRight → 보드 내부 메타 라인으로 이동(페이지도 동일).
  - `MarketTrendPanel` (market-trend/MarketTrendClient.tsx) — 시장지수 추세 그리드 카드.
    페이지는 패널 + 설명/SystemPoolGrid, 홈은 패널만.
- 홈 구성(`page.tsx`, 위→아래): ① 자산 요약(기존 대시보드) ② 24H 시세 ③ 시장지수 추세,
  각 블록에 섹션 헤더 + "전체 화면 →" 링크. 우측 메뉴 레일 유지.
- 시장추세 기준값(fetch) 실패 시 해당 블록만 안내 문구 — 홈 전체는 뜬다(허브 내결함성).

### P2c. 한 화면(뷰포트) 벤토 배치 — ✅ 완료 (2026-07-24)
- 블록을 세로로 쌓는 대신 **스크롤 없이 한 뷰포트**에 요약본으로 배치(`hubHomeViewport`,
  높이 = 100dvh − 헤더. 넘치면 블록 내부 스크롤, ≤1400px 에서는 일반 세로 배치로 폴백):
  - ① 자산 요약 스트립(`HubAssetSummary` 신설) — 핵심 지표 4 + 기간손익 4 를 한 줄 타일로.
    상세 대시보드(DashboardManager)는 **`/dashboard` 라우트로 이동**(기존 redirect 를 실제 화면으로 교체).
  - ② 24H 시세 compact — 시세 3장(나스닥/환율/VIX)은 좌측 세로 스택(차트 없음, 작게),
    비교 3장(하이닉스/마이크론/삼성)은 크게(차트 고정 높이 185px). `hubLive24hRow` CSS 그리드.
  - ③ 시장지수 추세 compact — 핵심 컬럼(지수/현재가/일간/추세/기간)만 남긴 그리드.
- 컴팩트화를 위한 프롭: `QuoteCard.compact`(차트 생략), `ComparisonChart.fixedHeight`,
  `ComparisonCard.compact`, `MarketTrendPanel.compact`(컬럼 필터). 원본 페이지는 동작 불변.
- (후속) 자산 요약 스트립은 홈에서 **제외**(HubAssetSummary 삭제) — 홈은 24H 시세 + 시장추세 2블록.
  자산 요약 상세는 루트 메뉴 "자산 요약"(/dashboard)으로 접근(사이드바·허브 메뉴 공용 ROOT_ITEMS 에 추가,
  AppShell 루트 메뉴는 ROOT_ITEMS 맵 렌더로 변경).
- (후속2) 홈 메인을 **24H 시세 전체판 단일 블록**으로 변경 — 시장추세 블록도 홈에서 빠지고
  메뉴(시장지수 추세)로 접근. `/live-24h` 라우트는 홈 redirect 로 교체(북마크 보호), 메뉴에서 24H 항목 제거,
  `HyperliquidClient` 래퍼 삭제(공용 `Live24hBoard` 만 유지). compact 프롭·CSS 는 재사용 대비 유지.

### P3b. 좌측 사이드바 제거 + 우측 메뉴 레일(홈 전용) — ✅ 완료 (2026-07-24)
- 데스크톱 **좌측 사이드바 제거**. 메뉴는 홈의 **우측 레일**(HubMenu + CNN/VKOSPI 감정위젯 + 로그아웃)로 통일.
  - 레일은 `AppShell` 이 `pathname === "/"` 일 때만 `appBody` 우측에 렌더(감정지표·로그아웃 데이터가 AppShell 에 있어 이동 없이 재사용).
  - 홈 외 화면은 사이드바/레일 없이 전체폭 + 상단 홈 버튼(🏠)으로 복귀.
- 제거: 사이드바 접힘 상태·토글 버튼·`FULL_WIDTH_ROUTES` 자동숨김 로직(P3). 모바일 햄버거 메뉴는 `navList` 재사용해 유지.
- CSS: `.appContentHome`(메인+레일 2열), `.appHomeRail`(sticky·스크롤), `.appHomeRailFooter`. HubMenu 의 옛 페이지-레이아웃 CSS(hubHomeLayout/viewport/live24h) 정리.
- 참고: P3(FULL_WIDTH_ROUTES 자동숨김)는 이 단계로 대체됨.

### P3. 전체폭 모드(라우트별 사이드바 숨김) — ✅ 완료 (2026-07-24) · P3b 로 대체
- `nav-menu.ts` 에 `FULL_WIDTH_ROUTES`(그리드 중심 화면 목록) 정의.
- AppShell 이 해당 라우트에서 **데스크톱 사이드바를 자동 숨김**(기존 collapsed 메커니즘 재사용).
- 탑헤더 좌측에 **홈(허브) 버튼** 추가 — 사이드바가 없어도 홈으로 복귀 가능.
- 수동 토글은 계속 동작(자동값보다 사용자의 명시 조작 우선, 화면 이동 시 자동값 복귀).
- 적용 화면(1차): `/assets`, `/asset-helper`, `/pools-rank`, `/pools-backtest`,
  `/kor-market-stock`, `/us-market-stock`, `/aus-market-stock`, `/kor-market-etf`, `/holdings_details`.
- 이후 화면별로 목록에 추가/제거하며 조정한다.

### P4. 허브 타일 라이브 요약 (진행 예정)
- 타일에 살아있는 요약 표시: 시장 레짐(⬆️/⬇️), 알람 트리거 수, 배치 상태, 계좌 수익률 등.
- 기존 API 재사용: `/api/market-trend`, `/api/alarms/badges`, `/api/system` 등.
- 타일 하나씩 점진 추가(각각 독립 배포 가능).

### P5. 평가 후 마무리 (진행 예정)
- 사용해보고 결정: 사이드바 유지(보조) vs 기본 숨김 vs 제거.
- 모바일 메뉴는 현행 유지(모바일은 사이드바 가림 문제 없음).

### P4. 홈 메인 위젯 — ✅ 1차 (2026-07-24)
- 홈 메인에 **시장지수 추세 4차트(2×2)**: 좌상 합성지수(CORE) · 우상 코스피(^KS11) ·
  좌하 나스닥100(^NDX) · 우하 필라델피아 반도체(^SOX). `HomeTrendCharts`(client) 가 자기완결형
  `MarketTrendChart` 를 ticker 별로 렌더(각자 /api/market-trend/history 조회). 우측 메뉴 레일 유지.
- 기간손익(금일/금주/금월/금년)은 헤더 → 홈 레일 CNN 아래 4줄로 이동. VKOSPI 위젯·API·서비스 제거.
